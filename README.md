# DeepRec: Deep Learning-Powered Product Recommendation

This project was developed as part of ISTM 6218 at The George Washington University. It aims to improve product recommendations using data-driven approaches like fraud detection, clustering, dynamic pricing, and hybrid recommendation systems.

## 📌 Project Highlights

- 🔍 **Fraud Detection:** Identifies suspicious review activity using rule-based heuristics.
- 💰 **Dynamic Pricing Model:** Predicts optimal prices using linear regression with 95% accuracy (R² score).
- 📊 **Customer Segmentation:** Uses KMeans clustering to group products based on revenue, ratings, and discounts.
- 🤖 **Recommendation System:** Combines TF-IDF and deep learning for improved product suggestions.
- 📈 **Data Cleaning & Visualization:** Handles missing data, price normalization, review analysis, and visual dashboards.

## 🧠 Technologies Used

- Python, Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn, NLTK, TensorFlow/Keras
- Jupyter Notebooks for modeling and visualization

## 📁 Files and Structure

- `notebooks/` — All major components are modularized in Jupyter Notebooks
- `data/` — Original dataset or sample (or provide download link if too large)
- `visuals/` — Graphs and charts from analysis
- `ISTM6218_Project_Report.pdf` — Final report submission

## 📊 Dataset

Amazon Product Review Dataset (curated via [Kaggle](https://www.kaggle.com/datasets/flavioqueiroz/amazon-product-analysis-and-recommendation-system))
